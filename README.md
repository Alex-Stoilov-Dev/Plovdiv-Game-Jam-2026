# The lost masks of my grandpa

This repository is home of the game we made during the **Plovdiv Game Jam 2026 (Part of the Global Game Jam)**

## Game Jam Theme - **masks**. 

It was our first game jam, so we decided to make something humble.

The game has 2 levels, where you jump past some gaps, avoid spikes, and unlock neat abilities.

Massive thank you to my team members, for getting me into doing this game jam. 

I won't be lying if I said the amount of merge conflicts on this project was insane. Just before publishing, we had seemingly merged everything together. 
Unfortunately, this corrupted the project, so I had to create a new Godot Project and manually import all of the files, and fix what was missing.

What we used to make this project happen:
- Godot Engine
- Git
- Sprites, Tile sets, Music, Backgrounds all from Itch.io
(Exccept for the Masks I found source images on a forum and manually traced the images, as well as creating the sprite sheets)
